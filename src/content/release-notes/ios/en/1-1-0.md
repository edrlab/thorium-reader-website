## Release Notes

For this first post-release build, we're focusing on improving PDF support.

- **New:** Support for search in PDF
- **New:** Support for Danish
- **Update:** Improved performances when opening up large PDF files
- **Fix:** We got rid of a bug related to Apple Intelligence when using PDF files
