## Release Notes

- **New:** Support for audiobooks (MP3, M4B, FLAC, AAC, WAV, MP4, OGG, OPUS and AIFF)
- **New:** Sleep timer for audiobooks and read aloud
- **New:** Cast audio using Airplay
- **New:** Voice selector for TTS (Text-to-Speech) voices
- **New:** Mini-player to control audio playback
- **New:** Now translated in Dutch
- **Update:** New layout and controls for the audio player
- **Update:** Support for 8 new fonts (Bitter, Inter, Georgia, Inclusive Sans, Lexend, Libron, Noto Sans and Noto Serif)
- **Update:** First round of optimizations for the iPhone Duo
