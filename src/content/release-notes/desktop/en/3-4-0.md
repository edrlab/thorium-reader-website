## What's new in 3.4.0

### Filtering and sorting ebooks and audiobooks
Publications displayed in the Library Grid View can now be filtered by Format, Language, Progression (Not Started, In Progress, Finished) and Tags. Publications can be sorted by Title, Author, Language, and Reading State. 

This was already a feature of the Library Table View, symmetry is good. 

Don't hesitate to add Tags to your ebooks to select them easily.

### Favourite Catalogs
You can now select your favourite Ebook and Audiobook Catalogs from third party providers using the star that appears on each Catalog card: they will be listed first.

### Accessibility
Thanks to the large community of users with specific needs who use Thorium Reader daily, we fixed several accessibility issues related to the support of mathematic equations in ebooks, read aloud on publications with footnotes and annotations, heading hierarchy and keyboard tab cycling order for screen reader users.  

## Technical Notes

Under the hood, there was a major technical upgrade in this version, improving speed and stability.

If you are curious, [a detailed list of new features, improvements and bug fixes is available on the project GitHub space](https://github.com/edrlab/thorium-reader/releases/tag/v3.4.0).
