## What's new in version 3.5.0

This version introduces:

- Annotations on PDF documents (on par with EPUB). In this version, only bookmarks can be exported or imported; exporting highlights will be added in the next version.
- The option to create additional storage space for your publications, to overcome the saturation of the default storage.
- A setting that activates the automatic removal of expired publications from the application library (useful when the application is installed on shared computers).

Thorium Reader 3.5 also fixes a series of minor issues found by our vibrant community of users and enhances accessibility features in several areas. For instance:

- A user can now paste an LCP passphrase in the LCP request field, or some text in the search field.
- We fixed an issue with some large DRM-protected PDF documents.
- This version supports system-installed network certificates available in the operating system's CA store. This consequently enables support for self-signed certificates commonly used in corporate environments.

The application has been localized in two new languages: Polish and Estonian, thanks to our friends in these countries.

The application icon has been modified: an open book is now present, on which the “Th” letters are drawn. The blue background is kept, which makes it different from the purple background of the mobile Thorium Reader version (currently on iOS, next year on Android). 

This new dedicated website provides detailed information on the desktop and mobile versions of the application and offers direct support from the EDRLab team.
