## What's new in 3.5.0

- **PDF annotations are now supported.** You can select text in PDFs and create highlights or notes, similar to the EPUB reader. PDF annotation import/export is not available yet.
- **Improved read-aloud controls.** EPUB Media Overlays and text-to-speech now support finer speed control, new keyboard shortcuts, and better highlighting options.
- **More control over highlighting.** You can disable sentence or word highlighting during read-aloud, and Media Overlays can use the same visual styles as TTS.
- **Additional storage location.** You can choose an extra folder where Thorium stores newly imported publications.
- **Shared computer mode.** Expired LCP loans and their related user data can be removed automatically, useful for libraries, schools, universities, and shared workstations.
- **Better window behavior.** Thorium now remembers maximized windows, restores Library display preferences, and adds settings for how the Library and Reader windows behave.
- **Windows system tray option.** On Windows, the Library window can be minimized to the system tray.
- **Deep link support.** Thorium can now open special links to add catalogs or publications directly.

## Improvements

- Better screen reader support and accessibility labels.
- More accurate display of EPUB accessibility metadata.
- Improved support for right-to-left languages.
- Updated translations, including Hebrew support.
- Search can now use the currently selected text.
- Right-click edit menus now work in text fields.
- More reliable LCP downloads, streaming, and license updates.
- Better recovery when publications are missing from storage or the internal database.
- Improved support for corporate networks using self-signed certificates.
- Windows installer and general application reliability improvements.

## Feature Details

### PDF annotations are now supported

You can now select text in a PDF to create highlights and notes, manage them from the annotation panel, edit their comment, color, style, and tags, and navigate back to them later. PDF annotations are saved in Thorium and restored when the PDF is reopened.

- PDF text highlights and notes are now supported.
- PDF annotations appear in the annotation panel.
- You can edit the comment, color, highlight style, and tags.
- You can delete PDF annotations.
- Clicking an annotation can navigate back to the PDF page or selection.
- Highlights are restored when reopening the PDF.
- Highlights stay aligned after zooming or rotating pages.
- Single-page and multi-line selections are supported.
- Multi-page selections are not supported yet.
- PDF annotations are stored by Thorium; they are not written back into the PDF file itself.
- PDF annotation import/export is not available yet.

Reference: PR [#3599](https://github.com/edrlab/thorium-reader/pull/3599), commit [23d9c093](https://github.com/edrlab/thorium-reader/commit/23d9c093b4a367578856289152c127053003fb58).

### Improved read-aloud controls

EPUB Media Overlays and TTS read-aloud now support finer playback speed control, from 0.2x to 6.0x in 0.1x steps. New keyboard shortcuts let you increase, decrease, or reset audio speed directly while reading.

- Speed control now works in smaller steps, so it is easier to find a comfortable reading pace.
- The speed range goes from 0.2x to 6.0x, in 0.1x increments.
- This applies to both EPUB3 Media Overlays and TTS read-aloud, depending on the active read-aloud mode.
- New keyboard actions were added:
  - Decrease audio speed: `Ctrl+5`
  - Increase audio speed: `Ctrl+6`
  - Reset audio speed: `Ctrl+7`
- These actions are also available in the keyboard shortcut settings.
- Reset brings the audio speed back to 1.0x.

Reference: PR [#3622](https://github.com/edrlab/thorium-reader/pull/3622), commit [061a720b](https://github.com/edrlab/thorium-reader/commit/061a720ba75ec08c4e7e813f8918902c0b844090). Fixes [#1154](https://github.com/edrlab/thorium-reader/issues/1154) and [#3589](https://github.com/edrlab/thorium-reader/issues/3589).

### More control over read-aloud highlighting

Read-aloud highlighting is now easier to adapt to your reading preferences. You can disable sentence and/or word highlighting during TTS read-aloud. EPUB Media Overlays can also use Thorium's custom TTS highlight styles, giving readers a more consistent visual experience.

- You can turn off sentence highlighting, word highlighting, or both during TTS read-aloud.
- EPUB Media Overlays can optionally use Thorium's custom TTS highlight styles instead of the publication's authored Media Overlay styling.
- This gives you more visual control when the default highlight style is distracting, too strong, or hard to read.

Reference: commit [3d379c33](https://github.com/edrlab/thorium-reader/commit/3d379c335bb22e70b024c8c16c31abe09884d81c), fixes [#3459](https://github.com/edrlab/thorium-reader/issues/3459); commit [c4aa4d57](https://github.com/edrlab/thorium-reader/commit/c4aa4d57a99822a7d8b6f07280606281400b03e7), fixes [#3460](https://github.com/edrlab/thorium-reader/issues/3460).

### Additional publication storage location

Thorium now lets you choose an additional folder for storing newly imported publications from Library Settings > Storage. Existing publications remain in their current location, and Thorium does not automatically migrate books when the storage folder is changed or removed. This feature is currently marked as beta.

- A new Storage section was added to Library Settings.
- You can configure an additional storage folder for newly imported publications.
- If no extra folder is configured, Thorium keeps using its default internal storage.
- Existing publications are not moved automatically.
- If you change or remove the additional storage folder, you must manually move existing publications if needed.
- Thorium warns users not to manually edit the storage folder contents.
- Publications stored in the additional folder are not compatible with Thorium 3.4 or earlier.

Reference: PR [#3529](https://github.com/edrlab/thorium-reader/pull/3529), commit [f80a3e3d](https://github.com/edrlab/thorium-reader/commit/f80a3e3db30650c3ad8c3c5f1108fa37e18c2c5c). Fixes [#3506](https://github.com/edrlab/thorium-reader/issues/3506). Related improvements: [023d817a](https://github.com/edrlab/thorium-reader/commit/023d817abd4c7bd746b022fa364e1ef8da6193ca), PR [#3561](https://github.com/edrlab/thorium-reader/pull/3561); [f091c9a4](https://github.com/edrlab/thorium-reader/commit/f091c9a497d12ea36b2630bae9a90d75f880e105).

### Shared computer mode

Thorium now includes an option to automatically remove expired or otherwise no-longer-usable LCP loans, along with associated local user data such as annotations and reading bookmarks. This helps keep shared computers clean in libraries, schools, universities, and other public workstation environments.

- A Shared computer mode setting was added to Library Settings.
- The setting is labelled: Automatically remove expired publications and associated user data.
- When enabled, Thorium can automatically remove LCP loans that are no longer usable.
- Removed data includes the publication and local user data such as annotations, reading bookmarks, and reading state.
- Cleanup runs after startup, then periodically, and also when the setting is enabled.
- Thorium also checks during publication open/import flows, so an expired old LCP copy can be removed or replaced more cleanly.
- Automatic background cleanup deletes LCP publications when their status confirms a terminal state such as expired, revoked, returned, or cancelled.

Reference: PR [#3633](https://github.com/edrlab/thorium-reader/pull/3633), commit [c19a45f1](https://github.com/edrlab/thorium-reader/commit/c19a45f1cc2d352c88952e8da4f1794d9dfe6c29). Fixes [#3491](https://github.com/edrlab/thorium-reader/issues/3491).

### Better window and library behavior

Thorium now remembers maximized Library and Reader windows and restores them automatically. The Library also keeps view preferences such as grid/list mode, sorting, and visible table columns. New window behavior settings let you choose how the Library and Reader windows should behave while you read.

- Thorium now remembers whether Library and Reader windows were maximized, and restores that state.
- Library view preferences are saved, including grid/list display, table sorting, and hidden table columns.
- New window behavior settings were added:
  - Minimize the Library after opening Reader windows.
  - Keep the Library in the background after closing Reader windows.
  - Use one Reader window per publication, so reopening an already-open book focuses the existing Reader window instead of opening another one.

Reference: PR [#3666](https://github.com/edrlab/thorium-reader/pull/3666), commit [cdfcb971](https://github.com/edrlab/thorium-reader/commit/cdfcb9715fb62f986ddfda23337dbf54f5df889c), fixes [#3661](https://github.com/edrlab/thorium-reader/issues/3661); PR [#3677](https://github.com/edrlab/thorium-reader/pull/3677), commit [8c78e839](https://github.com/edrlab/thorium-reader/commit/8c78e8398105caeffe8a853370e130a7665eac54), fixes [#3639](https://github.com/edrlab/thorium-reader/issues/3639); PR [#3676](https://github.com/edrlab/thorium-reader/pull/3676), commit [a95a0770](https://github.com/edrlab/thorium-reader/commit/a95a0770a070b8690a74e021c7b69571a6038a3b), fixes [#3505](https://github.com/edrlab/thorium-reader/issues/3505).

### Windows system tray option

On Windows, you can now choose to minimize the Library window to the system tray. When enabled, Thorium keeps running in the notification area, and the tray icon can be used to show or hide the Library or quit the application.

- A new Windows-only setting was added: Minimize the Library to the system tray.
- When enabled, minimizing the Library window keeps Thorium running in the Windows notification area.
- The tray icon can show or hide the Library window.
- The tray context menu includes Show library / bookshelf and Quit Thorium.
- Thorium shows a Windows notification hint the first time the Library is minimized to the tray.
- This is only available on Windows.

Reference: PR [#3667](https://github.com/edrlab/thorium-reader/pull/3667), commit [e76cb117](https://github.com/edrlab/thorium-reader/commit/e76cb1176c54bb7c13a1a60fab9aab74cae03fce). Issue [#3662](https://github.com/edrlab/thorium-reader/issues/3662).

### Deep link support

Thorium can now open special links from websites, library portals, or catalog pages to add catalogs or publications directly. This makes it easier for a library or publisher to guide readers from a web page into Thorium.

- Thorium now supports links that start the add-catalog flow.
- Thorium now supports links that start the add-publication flow.
- These links work through Thorium custom URL schemes on supported platforms.
- On macOS, Thorium also supports Universal Links through `https://www.thoriumreader.com/add/...`.
- Catalog providers can use the [Thorium publication badge generator](https://www.thoriumreader.com/en/badge/publication/) to help create publication links.

Reference: PR [#3685](https://github.com/edrlab/thorium-reader/pull/3685), main commit [051dc9e0](https://github.com/edrlab/thorium-reader/commit/051dc9e03397bdb6ea683683caa0b68967abc231), follow-up commit [a723442a](https://github.com/edrlab/thorium-reader/commit/a723442aed2f5fa7b0f9f6c04cd3b40354e5cca7). Fixes [#3684](https://github.com/edrlab/thorium-reader/issues/3684).
