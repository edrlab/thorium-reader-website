date: "2026-07-03"
---

This website is designed to comply with the technical standard for websites level ‘AA’ of the Web Content Accessibility Guidelines (WCAG) version 2.2.

This site was tested with Axe Dev Tools and with Voice Over on Chrome on MacOS Tahoe 26.5.1. No accessibility blockers were found. Last testing: July 2026.

You should be able to:

* zoom up to 200% without problems
* navigate the website using just a keyboard
* navigate the website using a modern screen reader and speech recognition software (on your computer or phone)

If you encounter any difficulties you can inform us via direct email to accessibility@edrlab.org

*Information about the accessibility of the app can be found at the [legal notices page](../legals/).*
